## 一、项目简介

**Treeks** 是一款采用 Apple 液态玻璃设计风格的多用户 Markdown 日记应用，具备以下核心能力：

| 模块 | 能力 |
| --- | --- |
| 日记编辑 | Markdown 实时预览、三模式切换、心情/天气/标签、置顶 |
| 日历日程 | 月历视图、日程颜色分类、日记关联查看 |
| 主题系统 | 7 套主题即时切换、用户独立保存 |
| 好友信件 | 好友请求、私信、附带日记分享 |
| 协同编辑 | 多人协作撰写同一篇日记、可见性精细控制 |
| 数据迁移 | 用户级 / 平台级 JSON、ZIP 导入导出 |
| 管理后台 | 用户管理、平台设置、操作日志、系统监控 |
| 系统清理 | 智能扫描垃圾文件并安全清理 |
| 移动适配 | 自动响应式布局、抽屉式侧边栏 |

**技术栈**：Node.js + Express + SQLite + 原生 HTML/CSS/JS + JWT + Puppeteer。

## 二、环境准备与安装

### 2.1 环境要求

- **Node.js** ≥ 18（推荐 20 LTS）
- 操作系统：Windows / macOS / Linux
- 浏览器：Chrome / Edge / Safari 最新版

### 2.2 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/cha3343954211/Treeks.git
cd Treeks

# 2. 安装依赖
npm install

# 3. 配置环境变量（可选，使用默认值也可运行）
cp .env.example .env

# 4. 启动服务
npm start
# 或开发模式（文件变更自动重启）
npm run dev
```

### 2.3 环境变量说明

编辑 `.env` 文件可调整以下配置：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口 |
| `JWT_SECRET` | 内置默认值 | **生产环境务必修改** JWT 签名密钥 |
| `JWT_EXPIRES` | `7d` | Token 有效期 |
| `UPLOAD_DIR` | `public/uploads` | 上传文件存储目录 |
| `MAX_UPLOAD_SIZE` | `10` | 单文件最大上传尺寸（MB） |

### 2.4 启动验证

启动成功后控制台会输出：

```
🌲 Treeks 服务已启动
   地址：http://localhost:3000
```

浏览器访问 [http://localhost:3000](http://localhost:3000) 即可看到登录页。

### 2.5 生产部署建议

```bash
# 使用 PM2 守护进程
npm install -g pm2
pm2 start server.js --name treeks
pm2 startup        # 开机自启
pm2 save

# 推荐 Nginx 反向代理 + HTTPS
```

部署清单：
- ✅ 修改 `JWT_SECRET`
- ✅ 配置反向代理与 HTTPS
- ✅ 设置数据目录定期备份
- ✅ 定期执行系统清理（见第十三章）

## 三、账户系统

### 3.1 注册账户

1. 访问首页，点击「注册」切换到注册页
2. 填写用户名（2-20 字符，支持中英文/数字/下划线）、密码（≥6 位）、昵称
3. 提交后自动登录并跳转主界面

> ⚠️ 若管理员关闭了注册开关，会提示「平台已关闭注册，请联系管理员」。

### 3.2 登录

输入用户名和密码登录。Token 有效期默认 7 天，期间无需重复登录。

### 3.3 默认管理员

- **账号**：`Chara`
- **密码**：`admin123`

系统也会在首次启动时自动将最早注册的用户设为管理员。如需手动指定，可直接修改 `users` 表的 `is_admin` 字段为 `1`。

### 3.4 修改个人信息

登录后点击右上角头像 → 「个人设置」，可修改：
- 昵称、个人简介
- 头像（上传图片）
- 主题偏好

## 四、日记核心功能

### 4.1 新建日记

点击侧边栏「日记」→ 右上角「新建日记」按钮，进入编辑器。

### 4.2 编辑器三模式

编辑器顶部提供三个模式切换按钮：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| **分屏** | 左编辑 / 右预览同步显示 | 默认模式，日常写作 |
| **编辑** | 仅显示编辑区，更宽 | 长文写作、专注输入 |
| **预览** | 仅显示渲染结果 | 最终校对、阅读 |

### 4.3 Markdown 语法支持

完整支持 GFM（GitHub Flavored Markdown）：

- 标题 `#`、列表 `-`/`1.`、引用 `>`
- 代码块 ` ```js ... ``` `（支持语法高亮）
- 表格、链接、图片、行内代码
- 任务列表 `- [x]`
- 删除线 `~~text~~`

代码块顶部会显示「红黄绿」三色模拟终端窗口的装饰效果。

### 4.4 日记属性

每篇日记可设置：

| 属性 | 说明 |
| --- | --- |
| **标题** | 必填，作为列表显示主标题 |
| **心情** | 😊😄😢😡等表情 |
| **天气** | ☀️🌧️⛅❄️ 等 |
| **标签** | 多标签，便于分类与搜索 |
| **置顶** | 列表顶部固定显示 |
| **可见性** | 私密 / 好友可见 / 指定用户 / 公开（详见第九章） |

### 4.5 自动保存

编辑过程中会自动保存草稿，避免意外丢失内容。底部状态栏会显示「已保存」时间戳。

### 4.6 搜索与筛选

日记列表支持多维度筛选：
- 关键词搜索（标题、内容、标签）
- 日期范围
- 标签过滤
- 心情 / 天气筛选

### 4.7 单篇导出

在编辑器右上角点击「导出」按钮，可将当前日记导出为：
- **Markdown**（.md）
- **PDF**（基于 HTML 模板，可选 default / elegant / cover 三种样式）

## 五、日历与日程

### 5.1 月历视图

侧边栏点击「日历日程」进入月历页面：
- **绿色圆点**：当日有日记，数字显示篇数
- **彩色色块**：当日有日程，颜色与日程颜色一致
- 点击某天 → 右侧显示当日日记列表与日程详情

### 5.2 日程管理

可对日程执行：
- **新建**：填写标题、描述、日期、起止时间、颜色、是否完成
- **编辑**：点击日程项修改
- **删除**：移除日程
- **标记完成**：勾选完成状态

### 5.3 日记关联

点击月历中某天后：
- 上半部分显示该日所有日记标题（点击可进入阅读）
- 下半部分显示该日所有日程

### 6.1 内置主题

侧边栏「主题设置」提供 7 套主题：

| 主题 | 主色调 | 适用场景 |
| --- | --- | --- |
| 🌳 森林绿 | 淡绿白 | 默认主题，护眼日常 |
| 🌊 海洋蓝 | 蓝色 | 偏好冷色调 |

## 七、好友系统

### 7.1 发送好友请求

1. 侧边栏点击「好友」
2. 在「添加好友」区域输入对方用户名
3. 可填写验证消息（最多 200 字）
4. 点击发送，等待对方确认

> 💡 若对方已先向你发送请求，系统会自动互相加为好友，无需重复确认。

### 7.2 处理好友请求

「好友」页面 → 「待处理」标签：
- **接受**：互加为好友
- **拒绝**：忽略该请求

### 7.3 好友列表

显示所有已互为好友的用户：
- 头像、昵称、在线状态指示点
- 点击好友可查看其公开日记
- 快捷操作：发信件、查看主页

### 7.4 删除好友

在好友详情页点击「解除好友」即可。解除后双方均不再出现在彼此好友列表。

## 八、信件系统

### 8.1 发送信件

仅限好友之间发送：

1. 进入「信件」页面 → 「写信」
2. 选择收件人（必须是好友）
3. 填写主题（最多 200 字）和正文
4. **可选**：附带一篇日记（自己的、或被授权可见/协作的日记）
5. 发送

### 8.2 收件箱与发件箱

- **收件箱**：收到的信件，未读会有标记
- **发件箱**：已发送的信件
- 信件支持「已读 / 未读」状态切换
- 包含日记的信件可直接打开日记查看

### 8.3 信件与日记可见性

附带的日记会临时授予收件人阅读权限，即便该日记本身是「私密」状态，收件人也能在信件中打开阅读。

## 九、日记可见性与协同编辑

### 9.1 可见性级别

编辑日记时可在「可见性」下拉中选择：

| 级别 | 说明 |
| --- | --- |
| **私密** (private) | 仅作者可见（默认） |
| **好友可见** (friends) | 作者的所有好友均可读 |
| **指定用户** (specific) | 从好友中勾选可见用户 |
| **公开** (public) | 平台所有登录用户可见 |

### 9.2 协同编辑

作者可邀请好友作为「协作者」共同编辑日记：

1. 编辑日记时点击「协作者」按钮
2. 从好友列表中添加协作者
3. 设置角色：
   - **editor**：可编辑内容
   - **viewer**：仅可查看
4. 协作者登录后即可在「共享给我的」中看到该日记

### 9.3 共享日记入口

侧边栏「共享日记」聚合显示：
- 好友公开 / 好友可见的日记
- 指定给你的日记
- 你被邀请协作的日记

## 十、图片与存储管理

### 10.1 上传图片

在日记编辑器中：
- 拖拽图片到编辑区
- 或点击工具栏图片按钮选择文件

上传的图片会自动归入「我的图片」库。

### 10.2 存储配额

每位用户有存储上限（默认 100 MB），可在以下位置查看：
- 个人设置页面 → 当前已用 / 总量
- 编辑器底部状态栏

上传文件超过配额时会拒绝并提示。

### 10.3 图片管理

侧边栏「我的图片」可：
- 查看所有已上传图片缩略图
- 复制图片 Markdown 引用
- 删除无用图片（同时释放存储）

## 十一、导出与备份（用户级）

### 11.1 我的数据导出

侧边栏「我的数据」→「导出数据」，支持两种格式：

| 格式 | 内容 | 适用场景 |
| --- | --- | --- |
| **JSON** | 仅元数据（日记、日程、图片元信息） | 数据迁移、备份 |
| **ZIP** | 元数据 + 图片文件 | 完整备份 |

### 11.2 数据导入

「我的数据」→「导入数据」：
1. 选择从其他平台导出的 JSON 文件
2. 可先点击「预览」查看将导入的内容
3. 选择「合并」模式导入
4. **去重策略**：按 `标题 + 内容 + 创建时间` 三元组判断重复，已存在则跳过

### 11.3 批量导出日记

在日记列表页：
- **批量选择**：勾选多篇后点击「批量导出」
  - MD：打包为 ZIP（含 README）
  - PDF：每篇生成 PDF 后打包为 ZIP，或合并为单个 PDF
- **导出全部**：一键导出所有日记

## 十二、管理后台

仅管理员（`is_admin = 1`）可见，登录后侧边栏会出现「管理后台」入口。

### 12.1 管理概览

展示四维统计卡片：
- **用户数**（绿色）
- **日记数**（蓝色）
- **图片数**（橙色）
- **存储占用**（紫色）+ 进度条

附加信息：
- 7 天注册 / 日记趋势双折线图
- 最活跃用户排行榜（金银铜徽章）

### 12.2 用户管理

- 用户列表：搜索、按状态筛选、分页
- 编辑用户：昵称、状态（active/disabled）、管理员权限、存储配额
- **重置密码**：随机生成新密码并返回
- **删除用户**：连带清理其上传文件与日记

### 12.3 平台设置

- **允许注册**：开关新用户注册
- **站点名称**：登录页与浏览器标题
- **站点公告**：登录页公告
- **默认存储配额**：新用户默认上限

### 12.4 操作日志

完整记录管理员所有操作：
- 更新设置、用户管理、重置密码、数据导入导出、清理操作
- 含操作时间、管理员、动作、目标、详情

### 12.5 数据管理（管理员级）

- **平台数据导出**：一键导出全平台数据（用户、日记、图片、日程、设置），支持 JSON 或 ZIP
- **平台数据导入**：从备份 JSON 恢复
  - 选项：跳过重复 / 覆盖
  - 安全：导入用户重置随机密码、强制 `is_admin=0`、按用户名去重

## 十三、系统清理

### 13.1 进入清理

管理后台 → 「系统性能」页面，自动扫描并展示可清理项。

### 13.2 清理分类

| 类别 | 说明 | 处理方式 |
| --- | --- | --- |
| **根目录垃圾文件** | `test-*`、`tmp-*`、`*.tmp`、`*.bak`、`*.log`、`.DS_Store`、`Thumbs.db` | 直接删除 |
| **孤儿上传文件** | uploads 目录有文件但数据库无记录 | 直接删除 |
| **空的上传目录** | 用户已删除但残留的空文件夹 | 删除空目录 |
| **数据库 WAL** | SQLite WAL 日志 | 执行 `wal_checkpoint(TRUNCATE)` |

### 13.3 使用流程

1. 进入系统性能页 → 自动扫描
2. 查看每类清理项的数量与大小
3. 点击「展开」可查看具体文件列表
4. 勾选要清理的目标
5. 点击「执行清理」→ 弹出确认对话框
6. 确认后执行 → 显示结果 → 自动刷新

### 13.4 安全保障

- **白名单机制**：仅清理明确匹配规则的文件
- **数据库反查**：上传文件清理前查询 `images` 表，仅删孤儿文件
- **用户数据保护**：日记、有效图片、账户、设置**永不删除**
- **WAL 安全合并**：通过 SQLite 官方命令合并，不直接删除
- **预览先行**：执行前可预览全部清理项
- **操作日志**：所有清理操作可追溯

## 十四、移动端使用

### 14.1 自适应布局

Treeks 已针对移动端优化，在以下断点均有良好表现：
- ≤ 900px：侧边栏抽屉化
- ≤ 768px：卡片单列、工具栏横向滚动
- ≤ 414px：弹窗底部滑出、编辑器头部纵向堆叠
- 横屏（max-height: 500px）：紧凑布局

### 14.2 移动端操作

- **打开侧边栏**：点击左上角菜单图标
- **关闭侧边栏**：点击遮罩层或再次点击菜单图标
- **编辑器**：工具栏可横向滚动，支持触摸操作
- **弹窗**：从底部滑入，圆角顶部，支持滑动关闭

### 14.3 访问方式

- 手机浏览器访问 `http://<服务器IP>:3000`
- 桌面 F12 → 设备模拟 → 选择 iPhone 12 / SE 等机型测试

## 十五、API 接口速查

所有接口均需在 `Authorization: Bearer <token>` 头中携带 JWT（除登录/注册/站点信息外）。

### 15.1 认证

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | 注册 |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/auth/me` | 获取当前用户 |
| PUT | `/api/auth/theme` | 切换主题 |
| GET | `/api/auth/site-info` | 站点信息 |

### 15.2 日记

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/diaries` | 列表（分页/筛选） |
| POST | `/api/diaries` | 创建 |
| GET | `/api/diaries/:id` | 详情 |
| PUT | `/api/diaries/:id` | 更新 |
| DELETE | `/api/diaries/:id` | 删除 |
| POST | `/api/diaries/export` | 批量导出 |
| GET | `/api/diaries/:id/export.md` | 单篇 MD |
| GET | `/api/diaries/:id/export.pdf` | 单篇 PDF |

### 15.3 用户级数据迁移

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/diaries/user-data/export` | 导出我的数据 |
| POST | `/api/diaries/user-data/import` | 导入数据 |
| POST | `/api/diaries/user-data/preview` | 导入预览 |

## 十六、常见问题（FAQ）

### Q1：忘记管理员密码怎么办？

直接修改 SQLite 数据库 `data/treeks.db` 的 `users` 表，或使用 Node 脚本重置：

```js
const bcrypt = require('bcryptjs');
const hash = bcrypt.hashSync('newpassword', 10);
// UPDATE users SET password = hash WHERE username = 'Chara'
```

### Q2：登录后页面显示异常？

按 **Ctrl + F5** 强制刷新浏览器缓存，清理旧的 CSS / JS。

### Q3：上传图片失败提示「配额不足」？

进入「我的数据」或「个人设置」查看已用空间，删除无用图片释放配额；或联系管理员调整存储上限。

### Q4：注册提示「平台已关闭注册」？

管理员可在「管理后台 → 平台设置」中打开「允许注册」开关。

### Q5：导出 PDF 失败？

PDF 导出依赖 Puppeteer，首次使用会自动下载 Chromium。如网络受限，可：
- 设置环境变量 `PUPPETEER_SKIP_DOWNLOAD=true` 后手动安装 Chromium
- 或改用 MD 导出

### Q6：批量导出 PDF 报「打包失败」？

已在新版本中修复（`Uint8Array` 转 `Buffer`）。若仍遇到，请升级到最新代码。

### Q7：日历显示的日记标题与实际日期对不上？

已修复时区偏移问题（`routes/diaries.js` 使用本地日期字符串而非 UTC）。请确保使用最新代码。

### Q8：好友发给我的消息显示「8 小时 ago」？

时间显示基于服务器时区。请确保服务器时区设置为 `Asia/Shanghai`（或对应时区）：

```bash
# Linux
export TZ=Asia/Shanghai
```

### Q9：移动端侧边栏打不开？

确保已加载最新 CSS（强制刷新一次）。点击左上角菜单图标即可打开抽屉式侧边栏。

### Q10：如何升级到新版本？

```bash
git pull origin main
npm install      # 如有新依赖
pm2 restart treeks
```

升级后建议执行一次「系统清理」释放旧版残留文件。
